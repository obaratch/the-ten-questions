# The Ten Questions

**地球外知性との最初の接触に備えて、10の質問を考えるための、オープンで多言語な試みです。**

[English](README.md)

> ドラフト・スナップショット: 2026-09-27

地球の外――あるいは、私たちが地球を記述するときの前提そのものの外――に由来する知性と会話できるようになったとき、最初に何を尋ねるべきでしょうか。

10問すべてを聞けるとは限りません。第1問の後で接触が終わるかもしれない。3問しか聞けないかもしれない。しかも、その場にいるのは、この質問を考えた本人ではなく、限られた時間の中で既存の手順を頼りにするオペレーターかもしれません。

そこで、このプロジェクトが表に出す答えは意図的に小さくします。**優先順位を付けた10の質問**です。

しかし、10問を選ぶためには、その何倍ものことを考えなければなりません。相手に「私」と「あなた」の区別はあるのか。個体と集団は分かれているのか。前後や因果を認識するのか。意図、対立、ネットワーク、希少性、世代、娯楽に相当するものはあるのか。そもそも、人間の言語に埋め込まれた前提を相手にも当てはめてよいのか。

その検討過程も、このリポジトリに残します。

## プロトタイプ

現在の作業中の10問は [QUESTIONS.md](QUESTIONS.md) にあります。順位も表現も暫定です。

これらの質問を使うには、その前に、応答を区別し解釈できる程度の通信が成立していなければなりません。この前段階を **Stage 0** と呼びます。Stage 0 は重要ですが、このプロジェクトの主題ではありません。数学、物理、言語学、工学を含む通信確立そのものの問題は、それぞれの専門領域に委ねます。

## 地球は複数形である

このプロジェクトに基準となる単一の人間言語はありません。日本語と英語を最初の作業言語とし、原文と翻訳ではなく、同じ試みの並列表現として扱います。翻訳してみて初めて見つかる曖昧さや不一致も、修正すべきノイズとは限りません。それ自体が、質問にどんな前提が埋め込まれていたかを教えてくれます。

将来、地球側で最初の接触に立ち会う存在が人間とは限りません。人工知性かもしれないし、その時代には別の主体が地球文明を担っているかもしれません。同じように、接触相手も、生物、個体、惑星上の存在、あるいは私たちの時空に属する存在とは限りません。

## 10問を越えて

10の質問は看板であって、聞いてみたいことの総数ではありません。

「酔いますか」「最後に戦争をしたのはいつですか」「“最近の若い者は”と思いますか」。一見すると脇道に見える質問でも、娯楽、ストレス、世代、社会構造、技術、対立の歴史を知る手掛かりになるかもしれません。

現在の10問に入らない候補も [CANDIDATES.md](CANDIDATES.md) に残します。選外になった理由や議論も、将来の判断材料になり得るからです。

## このプロジェクトの姿勢

接触については真剣に考えます。ただし、自分たち自身まで荘厳に扱う必要はないでしょう。

ユーモア、好奇心、寛容さは、雰囲気を柔らかくするためだけのものではありません。軽い質問だからこそ見える社会構造があるかもしれないし、笑える余地があることで、こちら側の思い込みに気付けることもあります。

目標は大きく設定します。**極度の不確実性のもとで、有用な相互理解をできるだけ早く進めること。**

作業原則は [MANIFESTO.md](MANIFESTO.md)、運営については [GOVERNANCE.md](GOVERNANCE.md)、参加方法は [CONTRIBUTING.ja.md](CONTRIBUTING.ja.md) を参照してください。

## 完成ではなくスナップショット

このプロジェクトに最終版は想定していません。日付付きのスナップショットを、その時点での判断として残します。Git のコミットは厳密な出自を示し、日付は「その時代の地球側が何を考えていたか」を読む手掛かりになります。

将来は、構造化されたソースデータから多言語の HTML / PDF を生成し、議論全体を頭から読める Reader 版として公開することも考えています。架空の接触シナリオを使って10問を試す SF も有用そうですが、それは中核成果物とは分けたサブプロジェクト候補です。
