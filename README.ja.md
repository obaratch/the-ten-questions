# 10の質問

**ファーストコンタクトに備えて10の質問を考えてみよう**

[English](README.md)

> ドラフト・スナップショット: 2026-09-27

人類でも(人類由来の)AIでもない地球外知性と出会った時、最初に何を尋ねるべきでしょうか。

時間は限られています。チャンスが何度もあるとは限りません。しかもその場にいるのは、この質問を考えた本人ではなく、ただ宇宙に送り出されただけの哀れな、そして少々面倒くさがりな、オペレーターかもしれません。彼(女)はただ上から一つずつ手順を追うしかありません。

それが、ファーストコンタクト・プロトコルとしての **10の質問** です。全部聞けるとは限りません。大事なことから聞きましょう。

10問を選ぶためには、その何倍ものことを考えなければなりません。相手の認識に自他の別はあるのか。個体が集まれば集団なのか。前後や因果を認識するのか。意図、対立、ネットワーク、希少性、世代、娯楽に相当するものはあるのか。そもそも、人類にとって当たり前の概念や言語との接点はあるのか。

その検討過程も、このリポジトリに残します。

## プロトタイプ

現在作業中の10問は [QUESTIONS.md](QUESTIONS.md) にあります。順位も表現も暫定です。

これらの質問を使うには、その前に、少なくとも何らかの通信が成立していなければなりません。この前段階を **Stage 0** と呼びます。Stage 0 は重要ですが、このプロジェクトの主題ではありません。数学、物理、言語学、工学を含む通信確立そのものの問題は、それぞれの専門領域に委ねます。

## 地球は複数形である

このプロジェクトに基準となる単一の言語はありません。発起人の都合により日本語と英語を最初の作業言語としますが、どちらかが原文というわけではなく、同じ試みの並列表現として扱います。翻訳して見つかる曖昧さや不一致は、地球には複数の文化と言語があることを教えてくれます。合意に至る努力は必要ですが、違いを許容することも重要です。

将来、地球側で最初の接触に立ち会う存在が人間とは限りません。AIかもしれないし、その時代には別の主体が地球文明を担っているかもしれません。同じように、接触相手も、炭素由来の生物とは限りません。ソラリスのように個体ですらないかもしれない、母星を持つとも限らない、あるいは私たちの時空に属する存在かも分かりません。

## 10問を越えて

10の質問はいわば看板であって、聞いてみたいことのすべてではありません。

「お酒を飲みますか」「最後に争ったのはいつですか」「“最近の若い者は”と思いますか」。一見すると脇道に見える質問でも、社会構造、ストレス、娯楽、技術、世代、対立(あるいはその緩和)の歴史などを知る手掛かりになるかもしれません。

現在の10問に入らない候補も [CANDIDATES.md](CANDIDATES.md) に残します。今は選外になった理由や議論も、将来の判断材料になりえます。とくにちょっとふざけているように聞こえるものは。

## このプロジェクトの方針

接触については真剣に考えます。ただしあまり真面目になりすぎる必要はないでしょう。

ユーモア、好奇心、寛容さは、雰囲気を柔らかくするためだけのものではありません。軽い質問だからこそ見える社会構造の機微があるかもしれないし、笑える余地があることで、思い込みから少し外に出られるかもしれません。

目標は大きく設定します。極度の不確実性のもとで、有用な相互理解をできるだけ早く進めること。

作業原則は [MANIFESTO.md](MANIFESTO.md)、運営については [GOVERNANCE.md](GOVERNANCE.md)、参加方法は [CONTRIBUTING.ja.md](CONTRIBUTING.ja.md) を参照してください。

## 完成ではなくスナップショット

このプロジェクトに最終版はありません。日付付きのスナップショットを、その時点での判断として残します。Git のコミットは厳密な出自を示し、日付は「その時代の地球側が何を考えていたか」を読む手掛かりになります。

将来は、構造化されたソースデータから多言語の HTML / PDF を生成し、議論全体を頭から読める Reader 版として公開することを考えています。架空のシナリオを使って10の質問を試す SF も書いてみたいところですが、それはサブプロジェクト候補として現時点では保留します。みなさんの想像力にも期待しています。
