# The Ten Questions

**地球外知性との最初の接触に備えて、10の質問を考えるための、オープンで多言語な試みです。**

> ドラフト・スナップショット: 2026-09-27

地球の外――あるいは、私たちが地球を記述するときの前提そのものの外――に由来する知性と会話できるようになったとき、最初に何を尋ねるべきでしょうか。

このプロジェクトは、表に出す答えを意図的に小さく保とうとします。**優先順位を付けた10の質問**です。接触は第1問の後で終わるかもしれません。3問しか聞けないかもしれません。このリストは、それを設計した本人ではないオペレーターが読んでも役に立つものであるべきです。

その短いリストの背後にある検討は、意図的にもっと大きなものです。個体性、集合、時間、因果、意図、対立、ネットワーク、希少性、翻訳、そして人間の言語に潜む前提についての議論も、すべて記録の一部です。

## プロトタイプ

現在の作業中のリストは [QUESTIONS.md](QUESTIONS.md) にあります。完成版ではなく、今後変わることを前提としています。

通信そのものは **Stage 0** として扱います。これらの質問が役立つ前に、参加者どうしが応答を区別し、解釈するための最低限信頼できる方法を確立する必要があります。このプロジェクトはその問題の存在を認めますが、ファーストコンタクト通信の数学・物理・言語学・工学を全面的に解決しようとはしません。

## 地球は複数形である

ここに基準となる単一の人間言語はありません。日本語と英語を最初の作業言語とし、原文と翻訳ではなく、同じ試みの並列表現として扱います。言語が増えることも、翻訳によって露わになる不一致も歓迎します。

将来、地球を代表して接触する存在が人間とは限りません。接触相手も、生物、個体、惑星上の存在、あるいは私たちの時空に属する存在とは限りません。

## 10問を越えて

10の質問は看板であって、会話のすべてではありません。現在の10問から外れていても興味深い質問は [CANDIDATES.md](CANDIDATES.md) に残します。

## このプロジェクトのふるまい

接触については真剣に考えますが、自分たち自身まで荘厳に扱うつもりはありません。ユーモア、好奇心、寛容さは飾りではなく、別の社会を理解するためのプローブになり得ますし、自分たちの前提を点検する手段にもなります。

成果物は小さくても、その背後の野心は大きいものです。**極度の不確実性のもとで、有用な相互理解を最大化すること。**

作業原則は [MANIFESTO.md](MANIFESTO.md)、運営については [GOVERNANCE.md](GOVERNANCE.md)、参加方法は [CONTRIBUTING.ja.md](CONTRIBUTING.ja.md) を参照してください。

## 完成ではなくスナップショット

このプロジェクトは最終版を目指しません。日付付きのスナップショットを歴史的な節目として公開することがあります。Git のコミットが厳密な出自を示し、日付が人間に読める歴史的文脈を示します。

将来は、構造化されたソースデータから多言語 HTML / PDF の Reader 版を生成することも考えています。架空の接触シナリオをストレステストとして使う可能性もありますが、それは中核成果物ではなく、将来のサブプロジェクト候補です。
