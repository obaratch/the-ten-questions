# Governance — draft

This project is intended to remain open to argument while retaining enough editorial coherence to produce a usable set of ten questions.

## Stewardship

While the founding host actively maintains the project, the host acts as a benevolent editor with final responsibility for:

- project scope and coherence;
- acceptance, rejection, and ordering of the ten questions;
- publication of dated snapshots;
- interpretation of the manifesto when contributions pull in incompatible directions.

This role is not a claim to represent humanity, Earth, any institution, any profession, or any language community.

## Open disagreement

Substantive decisions should be discussable in public issues, discussions, and pull requests once the repository is public.

Disagreement is not technical debt to be erased. Competing formulations, minority objections, rejected questions, and translation problems may be valuable historical material and should remain discoverable when practical.

## Manifesto changes

The manifesto is revisable, but changes to it deserve a higher editorial threshold than ordinary wording changes because it defines the character and scope of the project.

During the founding host's active stewardship, the host retains final editorial responsibility for manifesto changes.

## Succession

No stewardship is presumed permanent.

A future succession process should preserve at least three things:

1. the historical record;
2. the ability to publish coherent snapshots;
3. the explicit fact that no steward is *the* representative of Earth.

The details of succession are intentionally left open in this initial draft.
